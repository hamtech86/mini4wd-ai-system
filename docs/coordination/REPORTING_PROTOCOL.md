# 部門間報告・引継ぎ運用規約

- 制定日: 2026-11-20
- 対象リポジトリ: `hamtech86/mini4wd-ai-system`
- 管轄: 統括司令塔

## 1. 正本の保管場所

部門チャット間で共有する正式な報告書、引継書、設計書、審査結果は、本リポジトリに Markdown 等のファイルとして保存する。チャット本文を正本として扱わない。

## 2. チャットでの共有方法

チャットには原則として次の情報だけを記載する。

1. 報告の結論・状態（承認、条件付き、差戻し、保留等）
2. GitHub上のファイルへのリンク
3. 関連Issue / PR番号
4. 次の担当と必要な作業

長文仕様書や報告書をチャットへ全文貼り付けない。必要な場合も、確認対象の短い抜粋に限定する。

## 3. ファイル管理

- 部門別の報告書は、原則 `docs/reports/<department>/` に保存する。
- 統括審査結果は、原則 `docs/reports/central/` に保存する。
- ファイル名には日付、部門、文書の目的、版数を含める。
- 改訂時は既存文書の履歴を追跡できるようにし、審査済み文書を無断で上書きしない。
- 文書間の参照は相対パスまたはGitHub URLで明示する。

## 4. 承認権限

各部門は担当範囲の設計・検証・報告を行う。部門自身の報告をもって統括承認とみなさない。統括承認が必要な事項は、統括司令塔がGitHub上の提出物を確認し、審査結果を別文書として記録する。

## 5. 実装変更との分離

この規約は報告・文書共有の運用を定めるものであり、DB生成、DDL、Migration、ファームウェア変更、アプリ実装、PRマージ等の実行承認を与えるものではない。各作業は既存の承認条件と担当権限に従う。

## 6. 提出時の最低情報

各報告書には、文書IDまたは版数、作成日、担当部門、対象範囲、結論、未解決事項、関連Issue / PR、次のアクションを記載する。
