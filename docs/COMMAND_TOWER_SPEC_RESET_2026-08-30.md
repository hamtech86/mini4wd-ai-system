# 司令塔・仕様仕切り直し基準

作成基準日: 2026-08-30

## 1. 参照範囲

本書作成より前のチャット上の経緯・担当間のやり取り・未確定の判断は、新仕様の根拠として使用しない。

現行GitHubリポジトリは、現在存在するコードを調査する目的に限って参照する。

## 2. 司令塔の役割

司令塔は全体仕様を確定し、担当へ作業範囲を渡す。
担当は司令塔で確定していない仕様を独自に追加・変更しない。

## 3. Motor Analysisの完成対象

最終的にUIへ表示する必須推定値は次の4項目。

1. 推定無負荷回転数
2. 推定トルク
3. ブラシピークライフサイクル
4. 対応車重

表示系として3.0V換算と2.8V換算を扱う。

## 4. 入力原則

個体性能の推定には生ログを使用する。

基本入力:
- motor_voltage / 電圧
- current_avg / 電流
- PWM
- brush_peak_current等、ブラシイベントを表すログ

Motor Modelの公称値は基準・補助情報として扱い、公称値そのものを個体の推定結果として表示しない。

実測RPMは個体推定RPMの入力として使用しない。

## 5. 推定値の性格

4項目はすべて「推定値」と明示する。
特に推定無負荷回転数と推定トルクは、生ログから個体性能を推定した値である。

## 6. 算出式

算出式は司令塔が別途確定したものだけを正式式として採用する。
未確定の係数・式を担当側で推測して正式値として実装しない。

本書では式を再発明しない。式が確定した時点で本書または別の単一仕様書へ追記し、その版を実装基準とする。

## 7. 実機確認

暫定確認対象はCal7570。

確認経路:

生ログ → Motor Analysis → 4推定値 → 3.0V/2.8V表示 → PerformanceResult → UI

合格条件:
- 4項目がUIに表示される
- 値がゼロ固定・公称値固定になっていない
- 生ログを入力して算出経路が実際に動作する
- 3.0V換算と2.8V換算が区別して表示される

## 8. アンカー

上記の実機確認が完了し、4項目が正常表示された時点で、そのコミットを新しい基準アンカーとする。

## 9. 変更禁止事項

- 未確定の算出式を勝手に作らない
- 公称値を個体推定値として代用しない
- UI側で独自計算しない
- 司令塔の確定範囲を担当側で拡張しない
- 旧チャットの未確定情報を新仕様へ混入させない
